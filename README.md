DNA and RNA Transcription and Translation Program

This program takes DNA and RNA sequences and translates and transcribes them

This program allows for DNA and RNA sequences with:
- Spaces " "
- Hyphens "-"
- 5' and 3' 

Example of valid inputs:
```text
ATGCCATACGTTAGGCTAA
5'-ATG-CCA-TAC-GTT-AGG-CTAA-3'
5' ATG CCA TAC GTT AGG CTAA 3'
```

This program cannot read from 3' to 5'
Nucleotides must be capitalised
